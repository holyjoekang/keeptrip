## KeepTrip — 앱 설치 없이 링크로 여는 나만의 여행 가이드

**한 줄 정의**: Keep121이 단체를 지킨다면, KeepTrip은 **한 사람의 여행을 준비부터 기록·공유까지** 돕습니다.
**슬로건**: Every trip, kept. / 다녀온 길까지, 간직하다.

### 다섯 가지 기능
| 기능 | 하는 일 |
|---|---|
| **맞춤 준비** | 내 일정·카드·폰 기준으로 **꼭 챙길 것 / 돈 아끼는 것 / 신경 끌 것**을 나눔 (예: eSIM 지원 폰이면 로밍 대신 eSIM, 수수료 몇천 원 때문에 새 카드 발급은 건너뛰기). 결제 수수료처럼 자주 바뀌는 항목은 **출발 3일 전 재확인** |
| **오늘** | 다음 일정, 길찾기, 현지어 택시 주소 카드, 오늘 꼭 챙길 것 |
| **도착 해설** | 박물관·명소에 도착하면 짧은 음성 해설과 "여기서 꼭 볼 것 3가지"가 자동으로 열림 |
| **보이스 기록** | 말로 남기면 AI가 장소·음식·동행·추천으로 정리하고, 같은 시각의 사진과 묶음 |
| **여행 스토리** | 일정, 기록, 사진으로 여행기 초안을 자동 생성. 카카오톡 링크로 가족에게 공유하고 블로그로 내보낼 수 있음. "강추" 장소는 다른 사람에게 추천으로 전달됨 |

### 왜 필요한가
- **준비 단계**: 할 일은 많은데 조건(프로모션·수수료)은 계속 바뀝니다. 그래서 지난 경험이 이번에도 맞는다는 보장이 없습니다.
- **현장**: 해설을 찾아볼 여유가 없어 그냥 지나치기 쉽습니다.
- **여행 후**: 지금 방식(구글 독스 → AI 정리 → 코딩 → GitHub)은 도구를 잘 다루는 사람만 할 수 있습니다. KeepTrip은 이 과정을 누구나 할 수 있게 자동화합니다.

### Keep121과의 연결
| Keep121 (단체·B2B) | → | KeepTrip (개인·B2C) |
|---|---|---|
| 여행사 일정 | → | 맞춤 준비·오늘 |
| 가이드 도착 확인 | → | 도착 해설·날짜별 기록 |
| Keep Journey 앨범 | → | 여행 스토리 (같은 엔진) |
| Keep Home 가족 알림 | → | 귀국 후 스토리 링크 |

단체여행 고객이 다음 여행에서 KeepTrip 사용자로 이어지는 **재구매 접점**이 됩니다.

### 원칙과 형태
- **형태**: PWA라서 링크로 열고, '홈 화면에 추가'하면 앱처럼 쓸 수 있습니다.
- **위치**: 여행 기간에만, 본인이 동의한 경우에만 씁니다.
- **기록**: 본인 소유이며, 공유는 본인이 켜고 끕니다.
- **브랜드**: Keep121의 문 마크를 그대로 쓰고, 문 안의 점만 핀(지금 있는 곳)으로 바꿨습니다.

현재는 **콘셉트 단계**입니다. 화면 시안(5종)과 BI, 사이트 소개 페이지까지 만들었고, 실제 동작하는 시제품은 아직 없습니다.
